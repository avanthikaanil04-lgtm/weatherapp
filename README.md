# 🌤️ Python Weather Forecast Application

A Python application that fetches and displays 
real-time weather information using OpenWeatherMap API.

## 🛠️ Technologies Used
- Python 3
- OpenWeatherMap API
- Requests Library

## ✨ Features
- Real-time weather data fetching
- Displays temperature, humidity and conditions
- User input handling
- Exception handling for invalid cities
- API integration using Python Requests library

## ▶️ How To Run
1. Install requests: pip install requests
2. Add your API key in weather_app.py
3. Run: python weather_app.py
